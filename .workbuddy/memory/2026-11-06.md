## 移动端布局改造（word-wind）

需求：桌面端 UI/功能完全不变，仅新增移动端（≤768px）适配。

移动端自上而下顺序：搜索框 → 上一个/下一个（+随机）→ 单词卡片 → 底部设置区（默认折叠）。

实现要点：
- `src/App.tsx` 新增 `CardArea`、`SettingsSection`、`SettingsToggle`、`SettingsBody` 四个 styled 组件。
- 关键手法：`SettingsSection` / `SettingsBody` 在桌面端用 `display: contents`，移动端才切换为 `block`。这样把 Sidebar（固定左上）和按钮容器从 DOM 前面挪到末尾重排，桌面端因为都是 `position: fixed`（或零宽 flex item），视觉零变化。
- 折叠状态 `showMobileSettings` 默认 false；移动端设置面板内含 词库选择、进度显示、页码跳转、释义显隐、设置&反馈、不会的单词。
- 随机按钮移动端收成一个 52px 方块，用 `.random-label` 隐藏文字；桌面端 base `gap: 6px` 保持原样。
- `WordCard.tsx` 移动端收紧 padding/字号，并关掉 hover 位移（触屏粘滞）。
- `index.html` 移动端隐藏 GitHub 角标（原为 absolute 定位于右上，会压住新的顶部搜索框）。
- README 同步更新了移动端说明。
