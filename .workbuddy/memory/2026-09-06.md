## 环境注意事项（编译校验）

- 项目内 `yarn install` / `npm install` 会被沙箱 broker 拦（mkdir 被拒），装出来的 node_modules 是残缺的空目录（无 .bin、部分包空）。
- 可行校验办法：`cd ~/.workbuddy/binaries/node/workspace && npm i typescript react ...`（该目录向上没有 package.json，npm 会装到 `/Users/chenx/node_modules`），再把项目里残缺的 node_modules 临时 `mv` 改名让开，用 `/Users/chenx/node_modules/typescript/bin/tsc -p tsconfig.app.json --noEmit` 跑检查，跑完改名回来。唯一残留报错是 `TS2688 vite/client`（临时依赖里没装 vite），可忽略。
